# 🍔 Canteen Management System

A menu-driven **C programming + DSA project** for managing a college canteen.

## Features

- Food menu management
- Add new food items
- Update stock
- Place customer orders
- Pending order management using **Queue**
- Cancelled orders using **Stack**
- Food menu using **Linked List**
- Search food by name
- Sort food by price/name using **Bubble Sort**
- Automatic bill/receipt generation
- Order history using file handling
- Inventory and canteen statistics
- Persistent menu and order data

## DSA Concepts Used

| Concept | Use |
|---|---|
| Structure | Food and Order records |
| Linked List | Dynamic food menu |
| Queue | First-In-First-Out pending orders |
| Stack | Cancelled order history |
| Searching | Food-name search |
| Sorting | Price/name sorting |
| File Handling | Saving menu and order history |
| Dynamic Memory | Linked-list nodes |

## How to Run

### Windows

Open the project folder in VS Code terminal:

```bash
gcc main.c -o canteen.exe
canteen.exe
```

### Linux / macOS

```bash
gcc main.c -o canteen
./canteen
```

## Data Files

The program automatically creates:

- `menu.dat` — stores food menu and stock
- `orders.dat` — stores completed order history

These files are binary files generated by the program.

## Example Workflow

1. Open **Customer / Order Management**
2. View the food menu
3. Search or sort food
4. Place an order
5. Order enters the Queue
6. Admin serves the next order
7. Served order is saved in order history
8. If an order is cancelled, it is pushed into the Stack
9. Stock is automatically updated

## Time Complexity

- Food search: **O(n)**
- Add food at end: **O(n)**
- Display menu: **O(n)**
- Bubble sort: **O(n²)**
- Queue enqueue: **O(1)**
- Queue dequeue: **O(1)**
- Stack push: **O(1)**
